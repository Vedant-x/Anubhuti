# Anubhuti

*Where creativity meets spirituality.*

A Vastu, Jyotish, numerology and tarot studio that runs entirely in the browser: no server, no sign-up, no trackers. Install it on a phone from the browser menu (**Add to Home Screen**) and it works offline.

**Live site:** https://vedant-x.github.io/Anubhuti/

## What's inside

- **Home**: tiles for every tool, client follow-ups, birthdays and Ask Anubhuti.
- **Daily panchang and muhurat calendar**: tithi, nakshatra, yoga, karana with end times, Rahu Kaal, choghadiya, hora, festivals, and good days for any activity.
- **Vastu studio**: guided steps (upload or draw, mark the centre with A-B-C-D, mark the boundary, choose side and degree), 16 zones, 32 entrances, 45 devtas, cut and extension detection, room and object checks, reports.
- **Kundli**: North or South Indian charts, all 16 divisional charts, planets with KP lords, chara karakas, aspects, avasthas, Vimshottari and Yogini dasha, yogas and doshas, Mangal dosha with cancellations, Sade Sati timeline, KP cusps and event scan, Ashtakavarga, Varshphal, Lal Kitab, Prashna.
- **Match making**: 36-guna with standard tables and an explanation for each koota, dosha cancellations, Mangal dosha balancing, 10 porutham, overall verdict.
- **Numerology, tarot, 27 nakshatras, remedies, calculators, compass, library, family vault and client manager.**

Calculations: Lahiri ayanamsa (Swiss Ephemeris definition), ΔT applied, JPL orbital elements for planets and Meeus series for the Moon. Traditional guidance; consult a trusted acharya for major decisions.

## Editing

Source code is in `source/`. After changing it, run `node source/build.mjs` to rebuild `index.html`, then commit.
